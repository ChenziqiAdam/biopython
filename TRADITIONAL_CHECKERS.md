# Traditional checkers (generic software-correctness sanitizers)

Inactive unless `SCIBENCH_TRADITIONAL_LOG` names a writable file. Hooks are called from the instrumented modules.

- **BP-SWE-001** `ProteinAnalysis.instability_index` (Bio/SeqUtils/ProtParam.py) — denominator nonzero before division. Precondition: any call that reaches the division (any ProteinAnalysis sequence, including empty). Invariant: self.length is nonzero before it is used as a divisor. Observed immediately before `(10.0 / self.length) * score`. Alarm: self.length == 0.
- **BP-SWE-003** `ProteinAnalysis.protein_scale` (Bio/SeqUtils/ProtParam.py) — output array length invariant. Precondition: window >= 1. Invariant: len(scores) == max(0, length - window + 1). Observed after the sliding-window loop, before returning scores. Alarm: len(scores) != max(0, length - window + 1).
- **BP-SWE-004** `IsoelectricPoint.pi` (Bio/SeqUtils/IsoelectricPoint.py) — search-result bounds validity. Precondition: any call through the public pi() API (default or explicit min_/max_). Invariant: the returned pH lies within the initial [min_, max_] bracket. Observed after isoelectric_point() calls pi(), at the ProteinAnalysis call site. Alarm: result < min_ - 1e-9 or result > max_ + 1e-9.
- **BP-SWE-005** `IsoelectricPoint.charge_at_pH` (Bio/SeqUtils/IsoelectricPoint.py) — overflow without a cross-check. Precondition: any finite pH value passed to the public charge_at_pH API. Invariant: the returned charge is finite. Observed immediately after the two summation loops, and on the OverflowError path from 10 ** (pH - pK). Alarm: the computed charge, or the substituted sentinel on an OverflowError, is not finite.
- **BP-SWE-007** `GC_skew` (Bio/SeqUtils/__init__.py) — finiteness with no independent cross-check. Precondition: any sequence and window size accepted by the public API. Invariant: every windowed skew value is a finite float. Observed after the per-window loop, before returning values. Alarm: any element of values is not finite.
- **BP-SWE-008** `CodonAdaptationIndex.calculate` (Bio/SeqUtils/__init__.py) — denominator nonzero before division. Precondition: any DNA sequence accepted by calculate's own codon-legality checks. Invariant: cai_length (the count of codons contributing a log-odds term) is nonzero before it is used as a divisor. Observed immediately before exp(cai_value / cai_length). Alarm: cai_length == 0.
- **BP-SWE-010** `Tm_GC` (Bio/SeqUtils/MeltingTemp.py) — denominator nonzero before division. Precondition: any sequence accepted by _check/strict (the empty string is not rejected by either). Invariant: len(seq) is nonzero before it is used as a divisor (the mismatch-percentage term and the C/N term both divide by it). Observed immediately after the strict-ambiguity check, before the first division. Alarm: len(seq) == 0.
- **BP-SWE-012** `salt_correction` (Bio/SeqUtils/MeltingTemp.py) — denominator nonzero before division. Precondition: method == 7 and any seq accepted by the function's own precondition check. Invariant: 2.0 * (len(seq) - 1) is nonzero before it is used as a divisor. Observed immediately before method 7's final expression, which divides by 2.0 * (len(seq) - 1). Alarm: len(seq) == 1.
- **BP-SWE-013** `Tm_NN` (Bio/SeqUtils/MeltingTemp.py) — domain error on a documented-valid input. Precondition: any dnac1/dnac2 (or dnac1 alone when selfcomp) accepted by the public API. Invariant: k = (dnac1 - dnac2/2) * 1e-9 (or dnac1 * 1e-9 when selfcomp) is strictly positive before math.log(k). Observed immediately before math.log(k). Alarm: dnac1 <= dnac2 / 2.0 (or dnac1 <= 0 when selfcomp).
- **BP-SWE-014** `Tm_NN` (Bio/SeqUtils/MeltingTemp.py) — finiteness with no independent cross-check. Precondition: any input accepted by the public API. Invariant: the final melting_temp is a finite float. Observed after all saltcorr branches (including the 6/7 second-division branch) have been applied. Alarm: melting_temp is not finite.
- **BP-SWE-016** `Vector.angle` (Bio/PDB/vectors.py) — denominator nonzero before division. Precondition: any two Vector objects reaching the public angle() method. Invariant: both vector norms are nonzero before their product is used as a divisor. Observed immediately before c = (self * other) / (n1 * n2). Alarm: n1 == 0 or n2 == 0.
- **BP-SWE-017** `calc_angle / calc_dihedral` (Bio/PDB/vectors.py) — return-value range contract. Precondition: any four (or three) points accepted by the public API. Invariant: calc_angle's return lies in [0, pi]; calc_dihedral's own docstring states its return lies in ]-pi, pi]. Observed immediately before returning the computed angle. Alarm: the angle is not finite, or falls outside the function's own documented range.
- **BP-SWE-018** `rotmat` (Bio/PDB/vectors.py) — array shape invariant. Precondition: any two Vector arguments accepted by the public API. Invariant: the returned array has shape (3, 3). Observed immediately before returning rot. Alarm: rot.shape != (3, 3).
- **BP-SWE-019** `Vector.normalize` (Bio/PDB/vectors.py) — overflow without a cross-check. Precondition: any Vector with a nonzero (but not necessarily large) norm. Invariant: the normalized components are finite. Observed immediately after self._ar = self._ar / self.norm(). Alarm: any component of the normalized array is not finite.
- **BP-SWE-020** `Superimposer.set_atoms` (Bio/PDB/Superimposer.py) — array shape invariant. Precondition: any two equal-length atom lists accepted by the public API. Invariant: self.rotran[0] has shape (3, 3) and self.rotran[1] has shape (3,). Observed immediately after self.rotran = sup.get_rotran(). Alarm: rot.shape != (3, 3) or tran.shape != (3,).
- **BP-SWE-021** `Superimposer.set_atoms` (Bio/PDB/Superimposer.py) — finiteness with no independent cross-check. Precondition: any two equal-length atom lists accepted by the public API. Invariant: self.rms is a finite float. Observed immediately after self.rms = sup.get_rms(). Alarm: self.rms is not finite.
- **BP-SWE-022** `QCPSuperimposer.set / QCPSuperimposer.run` (Bio/PDB/qcprot.py) — empty-container access producing NaN. Precondition: a 0-atom coordinate array passed to the public set()/run() API. Invariant: self.rms is finite even for a 0-atom input, OR the function raises a clear exception rather than silently propagating NaN. Observed immediately after run() computes self.rms. Alarm: self._natoms == 0 and self.rms is not finite.
- **BP-SWE-023** `QCPSuperimposer.run` (Bio/PDB/qcprot.py) — finiteness with no independent cross-check. Precondition: any non-empty coordinate pair accepted by the public API. Invariant: self.rms is a finite float. Observed immediately after run() computes self.rms. Alarm: self._natoms > 0 and self.rms is not finite.
- **BP-SWE-024** `PairwiseAligner.score` (Bio/Align/__init__.py) — finiteness with no independent cross-check. Precondition: any pair of sequences accepted by the input-conversion code. Invariant: the returned score is a finite float. Observed immediately after result = super().score(seqA, seqB, strand). Alarm: result is not finite.
- **BP-SWE-027** `DistanceTreeConstructor.upgma / DistanceTreeConstructor.nj` (Bio/Phylo/TreeConstruction.py) — discrete-structure (leaf-count) identity. Precondition: any DistanceMatrix accepted by the public API. Invariant: the constructed tree has exactly len(distance_matrix) terminal (leaf) clades. Observed immediately before returning the constructed tree (all upgma/nj return points). Alarm: len(list(tree.get_terminals())) != len(distance_matrix.names).
- **BP-SWE-029** `DistanceTreeConstructor.upgma / DistanceTreeConstructor.nj` (Bio/Phylo/TreeConstruction.py) — set-equality bookkeeping identity. Precondition: any DistanceMatrix accepted by the public API. Invariant: the output tree's leaf names are exactly the input taxon names, with no duplicates and no omissions. Observed immediately before returning the constructed tree (all upgma/nj return points). Alarm: the multiset of leaf names has a duplicate, or the leaf-name set differs from distance_matrix.names.
- **BP-SWE-030** `DistanceTreeConstructor.upgma` (Bio/Phylo/TreeConstruction.py) — finiteness of intermediate state. Precondition: any DistanceMatrix accepted by the public API. Invariant: the working distance matrix contains no NaN/Inf after any averaging update step. Observed after each merge step's del dm[min_i], inside the main while loop. Alarm: any entry of the working matrix is not finite.
- **BP-SWE-031** `PositionSpecificScoringMatrix.calculate` (Bio/motifs/matrix.py) — bounds validity before an array allocation. Precondition: any sequence and motif length accepted by calculate's own alphabet/type checks (the docstring states no minimum sequence length). Invariant: n - m + 1 (the requested scores-array size) is non-negative before np.empty is called. Observed immediately before scores = np.empty(n - m + 1, np.float32). Alarm: n < m.
- **BP-SWE-032** `PositionSpecificScoringMatrix.calculate` (Bio/motifs/matrix.py) — array shape invariant. Precondition: n >= m. Invariant: the output length equals exactly n - m + 1. Observed immediately after scores is populated by _pwm.calculate. Alarm: len(scores) != n - m + 1 (or, when a scalar is returned, n - m + 1 != 1).
- **BP-SWE-033** `PositionSpecificScoringMatrix.calculate` (Bio/motifs/matrix.py) — memory-initialization discipline. Precondition: n >= m and the sequence contains only A/C/G/T (the module's own comment documents that ambiguous bases are intentionally scored as NaN, so they are excluded from this precondition). Invariant: every returned score is finite. Observed immediately after scores is populated by _pwm.calculate. Alarm: any element of the result is not finite.
- **BP-SWE-034** `Alignment.shape` (Bio/Align/__init__.py) — definitional identity between two properties. Precondition: any Alignment object accepted by the public API. Invariant: alignment.shape == (len(alignment), alignment.length). Observed immediately before returning (n, m) from the shape property. Alarm: shape != (len(alignment), alignment.length).
- **BP-SWE-035** `Alignment.indices` (Bio/Align/__init__.py) — array shape invariant stated in the property's own docstring. Precondition: any Alignment object accepted by the public API. Invariant: indices.shape == alignment.shape. Observed immediately before returning the constructed index array. Alarm: indices.shape != alignment.shape.
- **BP-SWE-036** `CodonAligner.score` (Bio/Align/__init__.py) — finiteness with no independent cross-check. Precondition: any protein/nucleotide pair accepted by the input-conversion code. Invariant: the returned score is a finite float. Observed immediately after result = super().score(sA, sB0, sB1, sB2). Alarm: result is not finite.
- **BP-SWE-037** `GC123` (Bio/SeqUtils/__init__.py) — denominator nonzero before division. Precondition: any sequence accepted by the public API (the empty string is not rejected). Invariant: nall (the total A/T/G/C count across all three codon positions) is nonzero before it is used as a divisor. Observed immediately before gcall = 100.0 * gcall / nall. Alarm: nall == 0.
- **BP-SWE-038** `PositionSpecificScoringMatrix.max / PositionSpecificScoringMatrix.min` (Bio/motifs/matrix.py) — order identity between two independently implemented methods. Precondition: any PSSM accepted by the public API. Invariant: max() >= min(). Observed immediately before returning the summed score from max(). Alarm: max() < min().
- **BP-SWE-039** `DistanceCalculator._pairwise` (Bio/Phylo/TreeConstruction.py) — return-value range contract stated in the method's own docstring. Precondition: any two equal-length sequences accepted by the public get_distance API, with a substitution-matrix model (blastn/trans/blosum62/etc.). Invariant: the returned distance lies in [0, 1]. Observed immediately before returning 1 - (score / max_score). Alarm: distance < 0 or distance > 1.
- **BP-SWE-040** `ProteinAnalysis.gravy` (Bio/SeqUtils/ProtParam.py) — denominator nonzero before division. Precondition: any call that reaches the division (any ProteinAnalysis sequence, including empty). Invariant: self.length is nonzero before it is used as a divisor. Observed immediately before value = total_gravy / self.length. Alarm: self.length == 0.
- **BP-SWE-041** `PositionSpecificScoringMatrix.dist_pearson_at / dist_pearson` (Bio/motifs/matrix.py) — finiteness with no independent cross-check. Precondition: any two PSSMs of any length accepted by the public dist_pearson API. Invariant: numerator / denominator is a finite float. Observed immediately after computing numerator / denominator in dist_pearson_at. Alarm: the result is not finite (NaN or Inf).
- **BP-SWE-042** `salt_correction` (Bio/SeqUtils/MeltingTemp.py) — domain error on a documented-valid input. Precondition: method == 7 and any seq accepted by the function's own precondition check. Invariant: mg (the free-Mg2+ concentration used in method 7's final expression) is strictly positive before math.log(mg). Observed immediately before method 7's final expression, which calls math.log(mg) twice. Alarm: mg <= 0.
- **BP-SWE-043** `Alignment.inverse_indices` (Bio/Align/__init__.py) — array length identity stated in the property's own docstring. Precondition: any Alignment object accepted by the public API. Invariant: len(inverse_indices[k]) == len(alignment.sequences[k]) for every k. Observed immediately before returning the constructed list of index arrays. Alarm: any returned array's length differs from its corresponding sequence's length.
- **BP-SWE-044** `Alignment.counts (AlignmentCounts)` (Bio/Align/__init__.py) — counting-partition identity of a C extension's output. Precondition: any Alignment accepted by the public counts() API with no wildcard character configured (neither passed directly nor set on an aligner argument). Invariant: identities + mismatches == aligned. Observed immediately after constructing the AlignmentCounts object, before returning it from counts(). Alarm: identities + mismatches != aligned.
